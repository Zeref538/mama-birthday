# Birthday for Ma

A phone-friendly birthday greeting for Ma, born October 22, 1980. Personal message remains a clearly labeled placeholder at John's request.

Run locally: `python -m http.server 8080`, then open http://localhost:8080.

Edit the letter directly in `index.html`, inside the element with id `personal-message`. Push changes to main to publish through GitHub Pages. There are no packages, accounts, analytics or paid services used by this site.
