# Product

## Platform
web

## Users and purpose
John sends his mother a birthday greeting she can open on her phone. Success means a public GitHub Pages link with readable content and touch-friendly interactions.

## Content
Her name is Alma Merong. Address her as Ma. Birthday: October 22, 1980. Use a clearly labeled personal message placeholder; John will write it later. No photographs supplied.

## Stack
Plain HTML, CSS and JavaScript selected for GitHub Pages, with no build or dependencies.

## Language

English is the default, with an optional Filipino version. The personal letter remains untouched when switching language. The birthday card is in English. No language preference is stored.
